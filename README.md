# Abandoned Psychiatric Hospital Photos Archive

Архив фотографий заброшенных психиатрических больниц со всего мира.

## Структура проекта

```
.
├── photos/
│   ├── originals/          # Исходные фотографии (высокое разрешение)
│   └── thumbnails/         # Миниатюры для быстрой загрузки
├── metadata/
│   └── catalog.json        # Каталог всех фотографий и их описаний
├── docs/
│   └── CONTRIBUTING.md     # Инструкции по добавлению фотографий
└── README.md              # Этот файл
```

## Как добавить фотографию

1. Поместите оригинальное изображение в папку `photos/originals/`
2. Создайте миниатюру (макс. 300x300px) в папке `photos/thumbnails/`
3. Добавьте информацию о фотографии в `metadata/catalog.json`

## Формат метаданных

Каждая фотография должна иметь следующие метаданные:
- **id** - уникальный идентификатор
- **title** - название больницы
- **location** - местоположение (страна, регион)
- **year_closed** - год закрытия
- **filename** - имя файла фотографии
- **description** - описание фотографии
- **photographer** - имя фотографа
- **date_taken** - дата съемки

## Лицензия

Укажите лицензию фотографий при добавлении.
